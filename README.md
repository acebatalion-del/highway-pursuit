# Highway Pursuit

Playable test drive on the North Loop in New Meridian. Five cars, weighty handling, and a small city slice. Pursuits, traffic, and the garage economy come later.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Controls

- W / Up — accelerate
- S / Down — brake and reverse
- A D / arrows — steer
- Space — handbrake
- C — chase, hood, cockpit
- Click the view — mouse look
- R — reset on the south highway
- 1–5 — swap cars
- Esc — pause

A gamepad works too: triggers to drive, left stick to steer, A for the handbrake, Y for the camera, right stick to look, Start to pause.

ABS starts on. Traction control starts off. The river slows the car hard, and grass has less grip than the road.
